## 🔥 О проекте

**Tour to Hell** — это не просто туристический сайт. Мы создаем экстремальные путешествия для тех, кто ищет настоящие приключения и готов бросить вызов себе и природе. Наши туры проходят в самых опасных и захватывающих местах планеты: от вулканов Камчатки до пустыни Данакиль, от ледяного Оймякона до зоны отчуждения Чернобыля.

### Ключевые особенности:
- 🎨 Современный, адаптивный дизайн в стиле "адского" туроператора
- 🔐 Полноценная система авторизации и регистрации
- 🗺️ Интерактивные карты маршрутов с Яндекс Картами
- ❤️ Система избранного (Wishlist)
- 📝 Отзывы с модерацией
- 📊 Админ-панель с графиками и аналитикой
- 📧 Email-уведомления
- 📱 Полностью адаптивная верстка

## ✨ Функциональность

### Для пользователей:
| Функция | Описание |
|---------|----------|
| 🔍 **Каталог туров** | Просмотр всех доступных туров с фильтрацией и сортировкой |
| 📄 **Детальная страница** | Подробная информация о туре, программе, включенных услугах |
| 🗺️ **Интерактивная карта** | Маршрут экспедиции с точками и описанием |
| ❤️ **Избранное** | Добавление понравившихся туров в список желаний |
| 📝 **Отзывы** | Возможность оставить отзыв после прохождения тура |
| 📅 **Бронирование** | Многошаговая форма бронирования с выбором даты и участников |
| 👤 **Личный кабинет** | Просмотр своих бронирований и отзывов |

### Для администраторов:
| Функция | Описание |
|---------|----------|
| 📊 **Дашборд** | Графики и аналитика: конверсия, выручка, популярные туры |
| 🗺️ **Управление турами** | CRUD операции с турами, загрузка изображений |
| 📋 **Заявки** | Просмотр и управление заявками на бронирование |
| 📝 **Модерация отзывов** | Одобрение/отклонение отзывов перед публикацией |
| 📧 **Email-уведомления** | Автоматические уведомления о новых заявках |

## 🛠 Технологии

### Frontend:
- **React 18** - библиотека для пользовательских интерфейсов
- **React Router 6** - маршрутизация
- **Tailwind CSS** - стилизация
- **Framer Motion** - анимации
- **Recharts** - графики и диаграммы
- **Axios** - HTTP-клиент
- **React Hook Form** - управление формами
- **React Hot Toast** - уведомления
- **React Query** - управление состоянию сервера

### Backend:
- **Node.js** - среда выполнения
- **Express** - веб-фреймворк
- **MySQL** - база данных
- **JWT** - аутентификация
- **Bcrypt** - хеширование паролей
- **Multer** - загрузка файлов
- **Nodemailer** - отправка email
